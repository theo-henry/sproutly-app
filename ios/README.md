# Sproutly — iOS (SwiftUI)

Native SwiftUI iOS client. **Separate** from the Android Kotlin/Compose project at `../android/`
and the React/Vite web app at the repo root. The three workspaces share nothing
except the Supabase backend (when wired) and the design palette.

## Stack

- Swift 5.9, SwiftUI, iOS 17+ (uses the iOS 17 MapKit `Map(position:)` DSL, `MapCameraPosition`, and two-arg `onChange`)
- MapKit + CoreLocation for the Nearby tab (native equivalent of Android's MapLibre/Overpass)
- AVFoundation for the Scanner permission gate (placeholder, matches Android scaffold)
- **No SPM packages, no CocoaPods.** Zero external dependencies — CI build is one
  `xcodebuild archive` away.
- Xcode project is generated by [XcodeGen](https://github.com/yonki/XcodeGen) from
  `project.yml`. The `.xcodeproj` is gitignored on purpose.

matching screen across platforms is a one-line `cd`.

## First-time setup (requires macOS + Xcode 15.4+)

```sh
brew install xcodegen          # one-time
cd ios
xcodegen generate              # produces Sproutly.xcodeproj
open Sproutly.xcodeproj        # build & run in Xcode
```

Bundle identifier defaults to `com.sproutly.app`. Change it in `project.yml`
before signing for TestFlight / App Store.

## CLI build (unsigned, simulator-installable)

```sh
cd ios
xcodegen generate
xcodebuild \
  -project Sproutly.xcodeproj \
  -scheme Sproutly \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -archivePath build/Sproutly.xcarchive \
  CODE_SIGNING_ALLOWED=NO \
  archive

# Package the .app inside Payload/ → unsigned IPA
mkdir -p build/Payload
cp -R build/Sproutly.xcarchive/Products/Applications/Sproutly.app build/Payload/
( cd build && zip -qr Sproutly-unsigned.ipa Payload )
```

Output: `ios/build/Sproutly-unsigned.ipa`.

## Remote build (no local Xcode)

A GitHub Actions workflow at `.github/workflows/ios.yml` does exactly the steps
above on a `macos-14` runner.

- **Trigger:** automatic on push to `main` that touches `ios/`, or manually via
  the **Run workflow** button on the Actions tab (workflow_dispatch).
- **Artifact:** `Sproutly-unsigned-ipa` (the IPA) and `Sproutly-xcarchive`.
- **Download:** Actions → run → Artifacts.

## What kind of IPA do you get?

**Unsigned.** Suitable for:

- ✅ Hosting on the landing page as a downloadable file (for transparency / demo).
- ✅ Inspecting / re-signing later with a real Apple Developer account.
- ❌ **Not** directly installable on a stock iPhone. Apple requires the IPA to
  be signed by either:
  - a paid Apple Developer account (TestFlight / Ad Hoc), or
  - free-tier signing via Xcode → Run on a device tethered to your Mac, or
  - a third-party signer (AltStore / Sideloadly) with your own Apple ID.

For an installable distribution the next step is enrolling in the Apple
Developer Program (€99/yr) and uploading via TestFlight.
