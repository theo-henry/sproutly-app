# Design Direction

Sproutly should use a modern, futuristic visual direction.

Current project design preferences:

- Do not use orange, terracotta, clay, or warm orange-adjacent accents.
- Prefer Helvetica Neue or a similar clean neo-grotesk/system sans font stack.
- Use a sharper, more premium palette built around white, black, fresh green, cyan, and restrained AI-style violet accents.
- Add polished scroll-triggered reveal animations similar to modern Vercel-style websites.
- Keep the interface practical and product-like, with strong hierarchy, crisp borders, glass surfaces, and restrained motion.
