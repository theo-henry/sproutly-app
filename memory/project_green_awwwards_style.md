# Dark Green Awwwards-Inspired Style

Sproutly should use a sleek, modern, futuristic style based mostly on black and green.

Current direction:

- Use a dark green background as the dominant surface.
- Use lighter green highlights, but avoid neon or overly bright green.
- Keep the palette restrained with mostly different shades of green.
- Make the website feel like the web app itself inside a clean modern frame.
- Use a modern sans-serif font.
- Add varied animations for words, boxes, sections, navigation, and clickable elements.
- Motion should feel premium and Awwwards-inspired while still supporting usability.
